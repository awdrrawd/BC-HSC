# 遊戲內驗收清單

自動化測試是邏輯與模擬環境測試，無法涵蓋視覺、觸控與伺服器行為。以下項目需要在實際 BC 伺服器驗證（涉及他人的項目需兩個帳號）。完成後請直接從此清單刪除。

## 設定與儲存
- [ ] 調整清醒分鐘與延長開關、秒數，重新整理後仍保留
- [ ] 設定匯出再匯入；催眠中匯入時，停用的設定不會被強行套用
- [ ] 清除伺服器端設定的情境下，從本機（依帳號分開的）備份還原並補回伺服器
- [ ] 關閉頁面前最後一次變更不被 BC 的 2 秒 debounce 吞掉

## 催眠與效果
- [ ] 兩個帳號的表情還原保持同步；多個效果重疊結束後表情正確還原
- [ ] 強控中：自動清醒倒數、延長、清醒詞、`/hsc wake`；重新登入後依公告還原進度而不重播儀式
- [ ] 停用催眠系統後，他人頭上不再殘留進度球與符咒
- [ ] 識別障礙（面部／名稱）在關係網模式下遮蔽主人與戀人

## 遠端編輯與權限
- [ ] 三種編輯模式（僅自己／白名單／所有人）與白名單代號 `$owner`／`$lover`／`$friend`／`$white`
- [ ] 對方未安裝 HSC、已安裝但無權限、有權限三種個人資料頁按鈕狀態
- [ ] 與 LSCG、BCX、MPA 同載入時，遠端編輯畫面不被其他 mod 蓋過；回到個人資料頁後選中的角色正確

## 相容
- [ ] 以目前 BC 版本重新執行 `check:bc`；基準為 R133
- [ ] 催眠儀式動畫（符咒進場、穿到人物前方、移到頭部、震動）在不同視窗尺寸與高 DPI 螢幕上位置正確
